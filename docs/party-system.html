Sequence Diagrams

Party Creation

sequenceDiagram
    participant A as Client A (Creator)
    participant S as Server

    A->>S: SNSPartyCreateRequest
(login_session_id, max_members, party_json, member_json)
    alt success
        S-->>A: SNSPartyCreateSuccess
(party_id)
        Note over A: Stores party_id, sets self as owner
    else failure
        S-->>A: SNSPartyCreateFailure
(party_id, error_code)
    end

Player Joining via Invite

sequenceDiagram
    participant A as Client A (Host)
    participant S as Server
    participant B as Client B (Invitee)

    A->>S: SNSPartySendInviteRequest
(login_session_id, target_user_id)
    S-->>A: SNSPartyInviteResponse
(ack)
    S-->>B: SNSPartyInviteNotify
(time, party_id, sender_id, sender_name)
    Note over B: User sees invite in UI

    alt accept
        B->>S: SNSPartyRespondToInviteRequest
(target_user_uuid, param=1)
        S-->>B: SNSPartyJoinSuccess
(party_id, owner_id, members[])
        S-->>A: SNSPartyJoinNotify
(party_id, member_id, member_name)
    else reject
        B->>S: SNSPartyRespondToInviteRequest
(target_user_uuid, param=0)
        Note over S: No notification sent to host
    end

Player Joining Directly

sequenceDiagram
    participant B as Client B (Joiner)
    participant S as Server
    participant A as Client A (Host)

    B->>S: SNSPartyJoinRequest
(login_session_id, party_id)
    alt success
        S-->>B: SNSPartyJoinSuccess
(party_id, owner_id, max_members, locked, party_json, members[])
        S-->>A: SNSPartyJoinNotify
(party_id, member_id, member_name, member_json)
    else locked
        S-->>B: SNSPartyJoinFailure
(party_id, LOCKED)
    else full
        S-->>B: SNSPartyJoinFailure
(party_id, FULL)
    else not found
        S-->>B: SNSPartyJoinFailure
(party_id, NOT_FOUND)
    end

Kick Operation

sequenceDiagram
    participant A as Client A (Host)
    participant S as Server
    participant B as Client B (Kicked)
    participant C as Client C (Bystander)

    A->>S: SNSPartyKickRequest
(login_session_id, target_user_uuid, param)
    alt success
        S-->>A: SNSPartyKickSuccess
(party_id, kick_id)
        S-->>A: SNSPartyKickNotify
(party_id, kick_id)
        S-->>B: SNSPartyKickNotify
(party_id, kick_id)
        Note over B: kick_id == self: destroy party, reset state
        S-->>C: SNSPartyKickNotify
(party_id, kick_id)
        Note over C: kick_id != self: remove member from local list
    else failure
        S-->>A: SNSPartyKickFailure
(party_id, error_code)
    end

Lock / Unlock

sequenceDiagram
    participant A as Client A (Host)
    participant S as Server
    participant B as Client B (Member)

    rect rgb(40, 40, 80)
    Note over A,B: Lock Party
    A->>S: SNSPartyLockRequest
(login_session_id)
    alt success
        S-->>A: SNSPartyLockSuccess
        S-->>A: SNSPartyLockNotify

        S-->>A: SNSPartyUnlockSuccess

(party_id)
        S-->>B: SNSPartyUnlockNotify
(party_id)
        Note over A,B: dirty_flags &= ~0x10
    else failure
        S-->>A: SNSPartyUnlockFailure
(party_id)
    end
    end

Leave + Auto-Disband

sequenceDiagram
    participant A as Client A (Leaver)
    participant S as Server
    participant B as Client B (Remaining)

    A->>S: SNSPartyLeaveRequest
(login_session_id)
    alt success (members remain)
        S-->>A: SNSPartyLeaveSuccess
        S-->>B: SNSPartyLeaveNotify
(party_id, member_id)
        Note over B: Removes A from local member list
        Note over S: If A was host, auto-pass to next member
        S-->>B: SNSPartyPassNotify
(party_id, new_owner_id)
    else success (last member)
        S-->>A: SNSPartyLeaveSuccess
        Note over S: Party destroyed (no members remain)
    else failure
        S-->>A: SNSPartyLeaveFailure
(party_id, error_code)
    end
